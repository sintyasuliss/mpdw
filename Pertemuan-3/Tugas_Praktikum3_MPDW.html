Impor & Pembagian Data

Data yang digunakan adalah data kualitas udara New Delhi (observasi per jam), dengan AQI sebagai Y dan O3 sebagai X. Data dibagi menjadi data Training (75% data awal) untuk membentuk model dan data Testing (25% data akhir) untuk menguji akurasi ramalan.

# Impor Data
data_awal <- rio::import('/Users/sintyasulis/Downloads/NewDelhi_Air_quality.csv')

data <- data.frame(Yt = data_awal$AQI, Xt = data_awal$o3)

# Membagi data (54 observasi pertama untuk training, 18 observasi terakhir untuk testing)

# Mengubah format data menjadi objek Time Series (ts)
train.ts <- ts(train)
test.ts <- ts(test)
data.ts <- ts(data)

2. Model Koyck (PAKAI MLE bukan OLS jadi ga uji asumsi)

Model Koyck mengatasi masalah infinite distributed lag (pengaruh masa lalu yang tak terhingga) dengan mengasumsikan bahwa semakin jauh jarak lag, semakin kecil pengaruhnya.

Melalui transformasi aljabar, efek masa lalu dari X yang sangat panjang diringkas ke dalam satu variabel saja, yaitu \(Y_{t-1}\). Bentuk persamaannya menjadi:

\[Y_t=a(1-\lambda)+\beta_0X_t+\lambda Y_{t-1}+V_t\] Catatan: \(V_t\) adalah error term gabungan. Pada hasil ringkasan model (estimasi), \(V_t\) tidak ditampilkan karena nilai harapannya diasumsikan nol.

Pemodelan

Pemodelan ini menggunakan fungsi koyckDlm().

# Membangun Model Koyck
model.koyck <- koyckDlm(x = train$Xt, y = train$Yt)
summary(model.koyck)

3. Regression with Distributed Lag (DLM)

Berbeda dengan Koyck, pemodelan DLM membatasi secara spesifik berapa periode memori masa lalu yang dilibatkan. Batasan ini direpresentasikan dengan parameter \(q\).

$$Y_t=\alpha+\beta_0X_t+\beta_1X_{t-1}+…+\beta_qX_{t-q}+e_t$$

Pemodelan (Lag = 2)

Fungsi yang digunakan adalah dlm(). Parameter q = 2 berarti kita memasukkan \(X_t, X_{t-1}\), dan \(X_{t-2}\).

model.dlm <- dlm(x = train$Xt, y = train$Yt, q = 2)

4. Autoregressive Distributed Lag (ARDL)

Model ARDL menggabungkan pengaruh dari peubah independen masa lalu dan peubah dependen masa lalu.

Perhatian Notasi:

Pada package dLagM (khusus fungsi ardlDlm), aturannya adalah:

  • \(p\) = panjang lag peubah independen (\(X\)).

  • \(q\) = panjang lag peubah dependen (\(Y\)).

Pemodelan

# Model ARDL dengan lag X = 1 dan lag Y = 1 p(lag peubah independen X), q(lag peubah independen Y)
model.ardl <- ardlDlm(formula = Yt ~ Xt, data = train, p = 1, q = 1)
summary(model.ardl)

Lag Optimum ARDL

Kita bisa mencari kombinasi \(p\) dan \(q\) terbaik dengan fungsi ardlBoundOrders().

model.ardl.opt <- ardlBoundOrders(data = data.frame(data), ic = "AIC", formula = Yt ~ Xt)

# Menarik kombinasi lag dengan AIC terkecil
min_p <- c()
for(i in 1:6){
  min_p[i] <- min(model.ardl.opt$Stat.table[[i]])
}
q_opt <- which(min_p == min(min_p, na.rm = TRUE))
p_opt <- which(model.ardl.opt$Stat.table[[q_opt]] == min(model.ardl.opt$Stat.table[[q_opt]], na.rm = TRUE))

data.frame("Lag_Y_opt(q)" = q_opt, "Lag_X_opt(p)" = p_opt, "AIC" = model.ardl.opt$min.Stat)
##   Lag_Y_opt.q. Lag_X_opt.p.      AIC
## 1            2           13 16.55044
# Peramalan ARDL awal (p=1, q=1)

5. Pendekatan dengan Library dynlm dan Uji Asumsi

Pemodelan juga dapat dilakukan secara manual menggunakan library dynlm. Keunggulannya adalah kemudahan dalam memanggil fungsi uji asumsi sisaan (karena format outputnya setara dengan regresi linier standar lm).

Gunakan fungsi L() untuk memanggil nilai masa lalu (lag).

# Sama dengan DLM (q=1)
cons_lm1 <- dynlm(Yt ~ Xt + L(Xt), data = train.ts)

# Setara dengan Model Autoregressive Murni (Hanya melibatkan Xt dan Yt-1)
cons_lm2 <- dynlm(Yt ~ Xt + L(Yt), data = train.ts)

# Sama dengan ARDL (p=1, q=1)
cons_lm3 <- dynlm(Yt ~ Xt + L(Xt) + L(Yt), data = train.ts)

Uji Asumsi Model

1. Uji Autokorelasi (Durbin-Watson)

H0: Tidak ada autokorelasi

dwtest(cons_lm1)
## 
##  Durbin-Watson test
## 
## data:  cons_lm1
## DW = 1.0891, p-value = 8.131e-05
## alternative hypothesis: true autocorrelation is greater than 0

Interpretasi: P-value < 0.05, maka tolak H0 (ada autokorelasi), namun secara teori memang wajar terjadi pada data time series polutan udara per jam karena adanya pola musiman/siklus harian

2. Uji Heteroskedastisitas (Breusch-Pagan)

H0: Ragam sisaan homogen

bptest(cons_lm1)
## 
##  studentized Breusch-Pagan test
## 
## data:  cons_lm1
## BP = 1.4587, df = 2, p-value = 0.4822

Interpretasi: P-value > 0.05, sehingga gagal tolak H0 maka ragam sisaan homogen

3. Uji Normalitas (Shapiro-Wilk)

H0: Sisaan berdistribusi normal

shapiro.test(residuals(cons_lm1))
## 
##  Shapiro-Wilk normality test
## 
## data:  residuals(cons_lm1)
## W = 0.70298, p-value = 4.702e-09

Interpretasi: P-value < 0.05 sehingga tolak H0 maka sisaan model tidak berdistribusi normal. Hal ini mungkin disebabkan oleh adanya outlier polusi pada jam-jam tertentu
